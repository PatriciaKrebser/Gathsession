# Gathsession

Proyecto realizado para CSS Tarea Entregable 2 - Header Gathsession.

## Tecnologías

- HTML
- Sass (SCSS)
- CSS
- JavaScript
- Vite

## Ejecutar localmente

1. Instalar las dependencias:

   ```bash
   npm install
   ```

2. Iniciar el servidor de desarrollo:

   ```bash
   npm run dev
   ```

3. Para generar la versión de producción:

   ```bash
   npm run build
   ```
